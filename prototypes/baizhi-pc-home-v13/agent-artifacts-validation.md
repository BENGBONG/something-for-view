# Agent 产物合入验证

验证环境：Chromium、静态 HTTP 服务、1440×900；分别检查原始 `app.html` 与固定画布入口 `index.html`。本次为前端原型整合。

## 已通过的浏览器检查

1. 企业与个人销售简报目录各显示 6 个历史 XLSX，企业部门筛选显示 2 条匹配记录，并能与文件名搜索组合。
2. 来源说明在列表操作中打开独立弹窗，显示对应第 35 周快照；预览为内嵌表格。
3. 修改 C2 后切换首页 / 能力中心出现确认，继续编辑保留草稿；保存并离开后返回，表格保留修改。
4. 未修改内容但仍处于编辑状态，关闭预览、切换目录和开始录音均先提示。Esc 也触发离开确认，不会立即关闭新弹窗。
5. 通过 `window.__artifactFailNextSave = true` 注入一次保存失败，确认页面不跳转且错误提示可见；再次保存成功才进入目标模块。
6. 编辑后删除文件，企业回收站显示「企业文件/Agent 产物/销售简报 Agent」原位置；恢复后仍有 6 条记录，来源说明保留 v2。
7. 切到个人目录无部门筛选，企业副本的编辑不影响个人文件。Agent 系统目录没有选择框和删除入口。
8. 普通知识库保留原有 PDF / DOCX / 网页 / 目录，DOCX 也可在预览内编辑并保存；首页仍能正常返回。
9. 第 36 周任务结果支持选择企业保存；再次主动保存创建 `(1).xlsx`。跳转至 `index.html` 后知识库显示 6 份历史 + 2 份新文件，内嵌预览读取对应快照数据。
10. `index.html` 的 iframe 内编辑后点击首页，同样出现三选一确认，选择不保存后进入首页。
11. 个人版结果保存位置只有「我的文件」；未完成任务不可保存。另一个同源知识库标签页在保存后自动从 6 条更新到 7 条，并可打开本次快照。
12. 目标仓库已有 `tests/prototype-agent.e2e.cjs` 回归通过，覆盖专家参数、版本隔离、任务执行、工具详情、历史切换、文件面板及首页专家入口。

上述回归步骤中未捕获页面 JavaScript 异常。检查时发现并修复了目录选中态遍历错误及 Esc 默认取消确认框的问题。

## 手工复核与实现边界

- 来源信息仅说明文件来源，不在预览底部重复展示。
- 系统目录不可删除；普通文件仍使用目标原型的回收站逻辑。
- 本地存储仅模拟任务页到知识库的交付；真实的权限校验、XLSX 导出、WPS 保存回调及并发处理尚未接入。
