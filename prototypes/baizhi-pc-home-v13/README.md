# 百智 AI 工作台 v13 · 应用数据 v2.0

本轮在既有百智 PC 外壳上增加「应用数据」，替代早期 Agent 产物目录主流程。首页、会议、闪念、能力中心、普通文件及通用文件编辑保留。

## 入口

在线入口：[百智 PC · 应用数据](https://bengbong.github.io/something-for-view/prototypes/baizhi-pc-home-v13/index.html?edition=enterprise&page=apps)。本目录发布后通过 GitHub Pages 访问。

- `index.html?edition=enterprise&page=apps`：应用列表，固定 PC 画布。
- `app.html?edition=enterprise&page=apps&app=sales`：响应式多表详情。
- `index.html?edition=enterprise&page=apps&app=sales&run=run-0908-review`：固定运行的变更前后值。
- `agent.html?edition=enterprise&agent=商机复盘%20Agent&task=apps-sales-update`：任务结果页。
- 个人版将 edition 改为 personal。

## 当前规则

应用按 app_id 唯一展示；多 Agent 可更新同一个 App，一个 Agent 可写多个 App。普通用户在成功运行且实际提交变更后自动获得入口，只看本人行。企业管理员可查看当前企业授权的全部应用，创建者仅可管理自己的 App。

应用包含多张表，提供搜索、分页和更新历史。历史按 App/run 分组，显示触发人、Agent、状态、表和新增/修改/删除前后值。部分写入后失败保留历史但不触发首次入口。应用表只读，不提供文件保存、复制、移动、下载或 WPS 编辑。

原有普通我的文件支持复制/移动/删除，普通企业文件仅移动；均不可下载，删除为垃圾桶图标。普通文件的内嵌预览、WPS 模拟编辑与离开确认继续保留。

## 样例与演示边界

- 张伟、周宁：普通成员，数据互相隔离。
- 陈琳：销售洞察、客户商机的创建者，可查看对应应用的全部数据。
- 李敏：企业管理员，可管理三项应用。
- 许安：新成员，初始没有应用。先执行只读/失败，再成功写入可观察自动出现。
- 支持同 App 不同 Agent 更新、一次运行更新两个 App、首次写入、只读、部分写入后失败。
- 更新后提示刷新，最新表内容与固定运行变更可对照。

上面是样例模型包含的角色和场景，不代表当前页面提供切换身份的入口。按评审意见，已移除页头姓名、“演示设置”和常驻刷新按钮，并移除“我的应用数据 / 我管理的应用”Tab。列表统一显示可访问应用，同一应用不重复；管理范围在具体应用内选择。

“查看本次任务”直接进入对应运行的 Agent 任务详情页，不再打开重复摘要弹窗；返回应用更新历史时恢复原应用、范围、筛选与变更抽屉。任务页与历史共用运行记录，支持多应用结果及部分写入后失败。任务权限独立于应用权限：当前样例只为触发人提供任务详情，其他身份仍可查看已授权的应用变更，生产接入需按任务服务授权。任务执行过程为样例展示，未接入真实执行日志。

已知未完成项：历史字段暂依赖当前表定义；异常、撤权、同步延迟等场景未全部呈现。已移除“数据范围”文字、普通用户单独的“我的数据”按钮及“应用创建者”信息和空行，仅管理者保留范围切换；数据所属人与历史触发人仍保留。

## 本地运行与边界

在当前目录运行静态服务，例如 `python3 -m http.server 8798 --bind 127.0.0.1`。
本次同步静态交互原型，不部署业务服务；在线效果以 GitHub Pages 发布完成后的内容为准。

使用 localStorage `baizhi-apps-data-v2` 保存样例，sessionStorage `apps-demo-user` 保存演示身份。未连接真实 Agent Platform、Apps、WPS、身份系统或知识库后端。前端样例含多用户数据只为评审，生产环境必须服务端授权过滤。未模拟真实事务、实时推送或跨页数据库一致性。

当前主设计为项目工作区的《应用数据 PRD v3.4》，包含产品视角的接口清单及全链路时序图；需求文档仍在工作区，未上传本仓库。验证记录见 [应用数据验证](apps-data-validation.md)。

本轮任务页采用 Figma 百智 PC 规范，应用更新以约 78px 高的紧凑卡片展示。点击卡片右侧入口，在 AI Agent 工作台中查看本次变更或最新数据，并可切换应用、数据表及进入知识库。工作台保留工具调用、文件列表、修订文件页签，当前应用更新样例不生成文件。详见 [任务页设计说明](apps-task-workspace-design.md) 和 [视觉核对记录](design-qa.md)。
早期 Agent 产物说明已归档至 [v1.1 说明](archive/agent-artifacts-v1.1.md)，不可作为当前规则。
