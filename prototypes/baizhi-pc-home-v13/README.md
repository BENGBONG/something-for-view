- 当前表允许操作且记录属于本人时，双击业务单元格编辑（也支持聚焦后 Enter）；Enter 或失焦保存当前单元格，Esc 取消。移除“编辑”按钮，操作列保留垃圾桶删除。新增使用右侧抽屉，数据所属人固定为当前用户。
- “周期汇总”作为只读表样例；此配置仅用于演示，并非已读取线上 Apps 配置。必填标记按样例字段定义配置，正式产品应读取 Manifest，不按列的位置判断。
- 单元格在失焦或离开时先保存；保存失败或版本冲突保留草稿。新增抽屉未保存、或单元格保存失败后离开，提供继续编辑、放弃修改、保存并离开。
- 工具栏支持多条件筛选（同时满足）、多字段排序及优先级调整；先筛选、排序，再分页。左侧表导航可收起，底部支持页码和跳转。
- 支持当前页多选删除，只可勾选本人且当前表允许删除的记录，提交前再次确认清单。切换页码、表、范围或筛选后清空选择，不隐式选择其他页；提交时统一检查权限和记录版本。
- “记录信息”开关展示只读记录 ID、创建时间；业务字段支持文本、整数、数值、日期、日期时间、布尔、UUID、JSON 校验。客户商机的“跟进计划”提供日期时间、UUID、JSON 样例；JSON 编辑时 Shift+Enter 换行，Enter 保存。
- 操作仅保存至当前浏览器，不调用真实接口。手动内容修改不新增 Agent 任务或结构历史；不提供 AI 字段、结构编辑、公开/私有切换或他人数据代改。编辑与基础表格增量尚未同步 PRD。

## 当前规则

能力中心按版本展示：个人版菜单及页面标题为“技能·连接器·应用”，仅保留技能、连接器、应用三个页签，默认进入技能；企业版为“Ai 专家·技能·连接器·应用”，保留四个页签，默认进入专家。个人版直达专家页签的旧链接回退到技能，版本切换时同步重置默认页签；不改已有任务记录及应用数据。

应用按 app_id 唯一展示；多 Agent 可更新同一个 App，一个 Agent 可写多个 App。普通用户在成功运行且实际提交变更后自动获得入口，只看本人行。企业管理员可查看当前企业授权的全部应用，创建者仅可管理自己的 App。

应用包含多张表，提供搜索、字段筛选、排序、分页和结构变更历史。历史仅显示表结构、字段定义与版本变化，不展示业务记录内容前后值。应用表按权限支持本人记录的新增、双击修改和删除，不提供文件保存、复制、移动、下载或 WPS 编辑。

原有普通我的文件支持复制/移动/删除，普通企业文件仅移动；均不可下载，删除为垃圾桶图标。普通文件的内嵌预览、WPS 模拟编辑与离开确认继续保留。

## 样例与演示边界

- 张伟、周宁：普通成员，数据互相隔离。
- 陈琳：销售洞察、客户商机的创建者，可查看对应应用的全部数据。
- 李敏：企业管理员，可管理三项应用。
- 许安：新成员，初始没有应用。先执行只读/失败，再成功写入可观察自动出现。
- 支持同 App 不同 Agent 更新、一次运行更新两个 App、首次写入、只读、部分写入后失败。
- 更新后提示刷新，最新表内容与固定运行变更可对照。

上面是样例模型包含的角色和场景，不代表当前页面提供切换身份的入口。按评审意见，已移除页头姓名、“演示设置”和常驻刷新按钮，并移除“我的应用数据 / 我管理的应用”Tab。列表统一显示可访问应用，同一应用不重复；管理范围在具体应用内选择。

“查看本次任务”直接进入对应运行的 Agent 任务详情页，不再打开重复摘要弹窗；返回应用更新历史时恢复原应用、范围、筛选与变更抽屉。任务页与历史共用运行记录，支持多应用结果及部分写入后失败。任务权限独立于应用权限：当前样例只为触发人提供任务详情，其他身份仍可查看已授权的应用变更，生产接入需按任务服务授权。任务执行过程为样例展示，未接入真实执行日志。

已知未完成项：历史字段暂依赖当前表定义；异常、撤权、同步延迟等场景未全部呈现。已移除“数据范围”文字、普通用户单独的“我的数据”按钮及“应用创建者”信息和空行，仅管理者保留范围切换；数据所属人与历史触发人仍保留。

## 本地运行与边界

在当前目录运行静态服务，例如 `python3 -m http.server 8798 --bind 127.0.0.1`。
本次同步静态交互原型，不部署业务服务；在线效果以 GitHub Pages 发布完成后的内容为准。

使用 localStorage `baizhi-apps-data-v2` 保存样例，sessionStorage `apps-demo-user` 保存演示身份。未连接真实 Agent Platform、Apps、WPS、身份系统或知识库后端。前端样例含多用户数据只为评审，生产环境必须服务端授权过滤。未模拟真实事务、实时推送或跨页数据库一致性。

当前主设计为项目工作区的《应用数据与已发布应用 PRD v4.0》。历史范围已收窄为表结构变化，不再提供业务内容的逐条变更历史。接口清单和全链路时序图已同步调整；需求文档仍在工作区，未上传本仓库。验证记录见 [应用数据验证](apps-data-validation.md)。

知识库 App 的“数据表”保留内容区左侧多表导航、右侧紧凑网格。原“更新历史”改为“结构变更历史”：查看表/字段的原定义、新定义和结构版本，不显示业务单元格前后值。结构历史不提供来源、数据表、类型或日期筛选；按时间倒序显示全部有权查看的记录，保留分页、结构详情和关联任务入口。旧返回状态中的筛选条件不再影响历史展示；数据表本身的筛选和排序保留。

任务页沿用 Figma 百智 PC 规范与紧凑卡片。普通数据更新只有“查看最新数据”，确有结构调整才提供“查看结构变更”。“专家·技能·连接器”新增“应用”Tab，已发布样例卡片打开独立本地示例 URL；未接入真实发布目录。详见 [任务页设计说明](apps-task-workspace-design.md)。此前 [视觉核对记录](design-qa.md) 仅为旧版视觉记录，不覆盖新功能规则。
