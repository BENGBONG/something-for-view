# 百智 AI 工作台 v13

企业版 / 个人版双模式交互原型。

- 文档嵌入入口：`index.html`，使用固定 1440×900（16:10）PC 画布并按容器等比缩放
- 原始响应式页面：`app.html`
- 内容：我的会议、我的闪念、企业会议、知识库、AI 专家/技能/连接器、录音工作台、小智与桌面端引导
- 企业协作：管理员按姓名、手机号、工作邮箱、部门和账号状态发送邀请邮件；个人版提供企业试用申请入口
- 文件管理：首页录音和知识文件删除后进入 30 天回收站，支持恢复、彻底删除、个人/企业空间隔离与剩余容量展示
- 说明：页面中的数据、授权、连接器接入、删除和下载流程均为原型演示

## Agent 产物（2026-09-08 合入）

本次在 v13 原有知识库中整合 Agent 产物，不替换首页、会议、闪念、能力中心、录音或回收站。

- 知识库是非点击分组；个人与企业文件下分别自动创建「Agent 产物 / 销售简报 Agent」系统目录，目录不可重命名、删除或批量选择。
- 每个空间预置第 30–35 周共 6 份 XLSX。只将表格作为本期 Agent 产物，普通 PDF、DOCX、网页与自定义目录保留。
- 列表统一展示文件名、类型、大小、文件状态、创建人（姓名 + 组织路径）、更新时间、操作；企业目录增加部门筛选，可与来源、类型、日期、搜索组合使用。
- Agent 目录标题下显示 Agent 描述。点击文件进入原有知识库工作区的内嵌预览，列表通过「来源说明」弹窗查看 App、任务运行、快照、数据范围、导出配置与文件版本。
- 编辑入口位于预览右上角。XLSX 与现有 DOCX 演示通用 WPS 编辑交互，提供保存按钮；编辑期间切换目录、首页、能力中心、录音、账户入口或关闭预览均先确认「保存并离开 / 不保存离开 / 继续编辑」，未改内容也需确认。Esc 退出同样受保护；刷新或关闭浏览器使用浏览器原生提示。
- 保存编辑只更新该知识库副本；不改创建人、不新建文件、不回写 Apps，不改变任务运行快照。删除沿用 v13 原有 30 天回收站，恢复后保留原目录、来源与文件版本。
- Agent 任务页新增「第36周华东销售简报」已完成示例。点击 XLSX →「保存至 Agent 产物」；企业版可选个人/企业，个人版只可保存到个人。每次主动保存都生成独立文件，同名加序号；同次操作重试不重复创建。未完成任务的正式保存入口禁用。

### 演示边界

未连接 Agent Platform、真实 Apps 查询、WPS SDK 或知识库后端，不生成实际 XLSX 二进制文件，也不执行公式计算。本次未修改定时任务保存路径。

跨页保存使用同源 `localStorage`（键 `baizhi-v13-agent-artifacts-v1`），使任务页保存的文件在知识库页可见；请通过 HTTP(S) 同源访问，勿依赖不同浏览器的 `file://` 存储行为。删除此键可重置跨页保存数据。编辑、删除与回收站仍沿用本地会话演示，刷新恢复原始示例及已另存的快照。存储模拟不代表真实权限校验或并发事务实现。

完整校验记录见 [Agent 产物合入验证](agent-artifacts-validation.md)。
