# 商机线索原型：一级导航折叠设计

## 目标

根据浏览器批注完成三项调整：

1. 将商机线索说明改为“线索 Agent 的结果自动沉淀为线索文件，支持预览、导出，并支持使用积分解锁高价值字段。”
2. 将第三个线索文件的创建人由“李静”改为“小张”。
3. 为一级导航增加可逆的紧凑折叠状态。

## 折叠交互

- 点击顶部现有的侧边栏按钮，在展开态和折叠态之间切换。
- 展开态保持当前 200px 宽度和现有内容。
- 折叠态宽度约 56px，仅保留 Logo、一级菜单图标和账户头像。
- 折叠态隐藏品牌文字、新任务文字、菜单文字、任务子项、空状态文字、账户详情和箭头。
- 折叠态的菜单图标保持居中；通过 `title` 和 `aria-label` 提供名称。
- 二级导航和主内容不折叠，并随一级导航宽度变化自然左移。
- 按钮标题和图标状态随展开/折叠状态更新。

## 实现边界

- 继续使用当前单 HTML 的 CSS 与原生 JavaScript，不引入依赖。
- 折叠状态只在当前页面生命周期内保存，不新增本地持久化。
- 不调整其他导航、数据逻辑或视觉主题。

## 验证

- 页面加载后默认保持展开态。
- 点击折叠按钮后一级导航变为紧凑图标栏，二级导航和主内容仍可见。
- 再次点击后恢复原布局。
- 两处批注文案在列表页显示正确。
- 浏览器控制台无新增错误或警告。
